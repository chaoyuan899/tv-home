# TCL 55D6 Implementation Plan

> Use superpowers:executing-plans for inline execution.

**Goal:** Run the original TV Home on TCL 55D6 Android 5.1.1.
**Architecture:** Native Java Activity, existing wallpaper assets, API 22 compatible app discovery and explicit vendor fallbacks. Separate preview installation from default-home switching.
**Tech Stack:** Java 11 compiled/desugared to API 22 with Android SDK tools.
**Spec:** ../specs/2026-11-09-tcl55d6-design.md

## Global Constraints
- Android 5.1.1/API 22, ARMv7; no new runtime dependencies.
- No system uninstall, root, firmware changes or unrelated debloating.
- Device data and keys remain local.

## Review Focus
- No configured dock apps exist: fill from discovered apps and keep focus reachable.
- Ordinary LAUNCHER apps must appear once, TV entry preferred.
- Returning to unchanged apps preserves focus; removed apps cannot strand navigation.
- TCL does not implement standard Settings/TV input intents: explicit fallbacks.
- Old Android lacks cmd package: never run Google TV takeover scripts automatically.

## Tasks
- [x] Build baseline and run APK compatibility test (expect minSdk and app entry failures).
- [x] Adapt build, manifest, discovery, input/settings fallbacks and Chinese labels. Build and pass APK compatibility test.
- [x] Install as app, capture screenshots, exercise remote keys, launch app/settings/sources, return and inspect crash logs.
- [x] Prepare recovery, verify Home switching and restoration if supported; document remaining limits.
- [x] Independent review, final verification, commit/push adaptation branch and deliver APK/source links.

Device implementation adjusted as documented in the spec: no HOME category, opt-in accessibility redirect, shell-protected in-app recovery, vendor source-picker service and API 22 shadow guards. Final reboot and publication results are recorded in docs/tcl55d6-validation.md.
